# Client Management & Project Tracking System

This project is being developed for Web App Solutions as part of XISD6329 Work Integrated Learning.

The system is designed to centralise client management, project tracking, milestones, documents, invoices, reports and notifications.

## Planned Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- PostgreSQL
- Android Studio / Kotlin
- GitHub
- Azure DevOps

## Project Structure

- `web` - Website frontend
- `mobile` - Mobile application
- `api` - Backend and REST API
- `database` - Database scripts and design
- `tests` - Application tests

Task 1 development in progress.
