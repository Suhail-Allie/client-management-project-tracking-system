# Client Management & Project Tracking System

## Project Overview

The Client Management & Project Tracking System is being developed for Web App Solutions as part of the XISD6329 Work Integrated Learning module.

The system is designed to provide a central platform for managing clients, projects, milestones, documents, invoices, reports, notifications and system users.

The project continues the planning and prototype work completed during XISD5319 and develops the original Figma prototype into a working web interface.

## Task 1 Status

The Task 1 website frontend has been developed using HTML, CSS and JavaScript.

The current version includes responsive web pages, navigation, forms, filtering, search functions and frontend interactions.

Backend functionality, database persistence and the mobile application will be developed during the later stages of the project.

## Current Website Features

The website currently includes:

- Login page
- Administrator dashboard
- Client management
- Client details
- Project management
- Project details
- Milestone management
- Document management
- Invoice and payment management
- Reports and analytics
- Notifications
- User management
- Profile and settings
- Responsive navigation
- Search and filtering
- Frontend form validation
- PDF report printing
- CSV report export

## User Roles

The planned system supports the following user roles:

- Administrator
- Developer
- Finance Manager
- Client

Access to system functions will eventually be controlled according to the authenticated user's role.
